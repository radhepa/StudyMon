# Bootstrap Town connected-community location prompts

Generated with the built-in image-generation tool using
`bootstrap-town-exterior-v1.png` as the visual reference. All production files
are 1672×941 PNGs.

## Shared production direction

Use case: style-transfer. Production 16:9 top-down StudyMon game environment.
Preserve the reference scene's crisp handcrafted 32-bit pixel-art language,
elevated camera, object scale, dense forest border, broad readable paths, warm
daylight, timber construction, flowers, and lanterns. Ordinary travel paths are
warm ochre/russet packed dirt with worn grassy edges; reserve stone for short
door thresholds, structural stairs, retaining walls, and bridges. Environment
only: no people, creatures, UI, labels, readable text, logos, or watermark.
Every requested edge exit must remain unobstructed and every path must be wide
enough for two characters. Every visible door must connect to the shared path
network through a permanent inward-facing fence or hedge opening. Do not place
community boards or noticeboards in any scene.
