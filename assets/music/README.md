# Radio music

Drop audio files (mp3, ogg, wav or m4a) in this folder, then list each one in
`js/data/radio-songs.js`:

```js
{ id: 'my_song', name: 'My Song', artist: 'Someone', file: 'assets/music/my-song.mp3' },
```

Reload the game and the song shows up in the 📻 Radio panel next to the StudyMon logo.
